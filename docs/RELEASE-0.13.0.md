# Accolade 0.13.0

## Open any screenplay PDF and keep writing

Got a script only as a PDF? Open it, or drop it on the window. Accolade reads it back into a script you can edit: Final Draft's, Highland's, Fade In's, Word's and Lexington's own, a scan too with OCR. Open tells a screenplay from a novel by itself (a novel's opens as Markdown), and offers the other way in one tap. It used to be hidden until you tried opening something crazy; now it is on the start window, in File > New from a PDF…, and first on the new **Fun Things to Try**.

The same on the command line, for a whole folder of them:

```
lexington -i script.pdf -o script.fountain
```

## Fun Things to Try

A help page with a line for every feature, by moment: writing, rewriting, adapting, producing, exporting. Each line does what it says, on your script or on the sample. Help > Fun Things to Try, or the palette.

## Also new

- **Storyboard frames in open tools:** a frame is a plain file in the bundle, drawn in Inkscape, Krita, Glaxnimate or Synfig (Edit Frame in…), refreshed when you save there. Export the timing as OTIO; bring Storyboarder boards in, one way.
- **The Table Read** times a scene by its storyboard frames, and can show them beside the lines.
- **Citations:** CSL styles (APA, Chicago author-date, IEEE, Vancouver, or a .csl of your own) and numeric styles.
- **Screenplay sources:** a PDF source's page shown as printed with a looks-right tick, Keep Mine remembered, differences found on the right page.
- **Revision tab:** prose checks for Markdown and the source; dismissals kept beside or in the document.
- **File dialogs** sort files by kind (a screenplay PDF, a novel PDF) found from their content, fast.
- **Beats:** real-film ranges where a study measured them, the rest marked as convention.
