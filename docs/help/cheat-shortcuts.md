# Keyboard Shortcuts

Ctrl is Cmd on a Mac. All of them: [Keyboard Shortcuts](shortcuts.md).

## Writing

- **Tab** on an empty line: a cue; after the cue: its dialogue; in dialogue: (a parenthetical)
- **Enter** after a cue or parenthetical: dialogue; on an empty dialogue line: action; after a heading: action
- **Enter** in a list → the next item
- **Tab** on “Tab: …” — take it; **Esc** — put it away
- **Ctrl+K**, **F1** — the command palette; **F10** or **Alt** — the ribbon's key tips (the lock's letter switches Smart and Fixed)

## Vim mode

- Modes: **Esc** · **i a** · **I A** · **o O** · **v V**
- Moving: **h j k l** · **w b e** · **0 ^ $** · **gg G** · **Enter, Backspace** · **1 … 9**
- Changing: **d c y + a motion** · **dd cc yy** · **D C Y** · **x X** · **p P** · **J** · **r + a character** · **u, Ctrl+R**
- Text objects and the structure: **]] [[** · **]s [s** · **as is** · **aS iS** · **m + an object** · **Alt+j Alt+k** · **Alt+h Alt+l** · **Alt+J Alt+K** · **Alt+H Alt+L**
- Selecting: **a motion in visual mode** · **vas viS …**
- Search and commands: **/** · **:**
- Folds and the outline: **za zc zo** · **zR zM** · **Tab, Shift+Tab** · **gj gk** · **gh gl** · **gs**

## On a Mac

Option+Left and Option+Right move by word there, so these take Control+Option, and Cmd+H hides the app:

- **Cmd+Option+F** Replace
- **Control+M** Marker
- **Control+Option+M** Next Marker
- **Control+Shift+Option+M** Previous Marker
- **Control+Option+Left** Promote
- **Control+Option+Right** Demote
- **Control+Shift+Option+Left** Pass the Last Speech On
- **Control+Shift+Option+Right** Take In the Next Speech

## In the browser

The browser keeps Ctrl+N, Ctrl+T, Ctrl+W, Ctrl+Tab and Ctrl+PgUp/PgDn for its own windows and tabs, so these are others there:

- **Ctrl+Alt+N** New
- **Ctrl+Shift+Alt+N** New Empty
- **Ctrl+Shift+Alt+T** Title Page
- **Alt+PgDn** Next Middle Tab
- **Alt+PgUp** Previous Middle Tab
