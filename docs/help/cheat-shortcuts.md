# Keyboard Shortcuts

Ctrl is Cmd on a Mac. All of them: [Keyboard Shortcuts](shortcuts.md).

## Writing

- **Tab** empty line → cue → dialogue → (parenthetical)
- **Enter** cue → dialogue; empty dialogue → action; heading → action
- **Enter** in a list → the next item
- **Tab** on “Tab: …” — take it; **Esc** — put it away

## File

- **Ctrl+N** New
- **Ctrl+Alt+N** New Empty
- **Ctrl+Shift+N** New Window
- **Ctrl+Shift+Alt+N** New Empty Window
- **Ctrl+O** Open
- **Ctrl+S** Save
- **Ctrl+Shift+S** Save As
- **Ctrl+Shift+T** Title Page
- **Ctrl+E** Export
- **Ctrl+P** Print
- **Ctrl+,** Preferences

## Edit

- **Ctrl+Z** Undo
- **Ctrl+Shift+Z** Redo
- **Ctrl+F** Find
- **Ctrl+H** Replace
- **Ctrl+G** Find Next
- **Ctrl+Shift+G** Find Previous

## Format

- **Ctrl+1** Scene Heading
- **Ctrl+2** Action
- **Ctrl+3** Character
- **Ctrl+4** Parenthetical
- **Ctrl+5** Dialogue
- **Ctrl+6** Transition
- **Ctrl+7** Centered
- **Ctrl+8** Lyrics
- **Ctrl+Shift+L** Scene or Section Color
- **Ctrl+B** Bold
- **Ctrl+I** Italic
- **Ctrl+U** Underline
- **Alt+Up** Move Line Up
- **Alt+Down** Move Line Down

## Adaptation

- **Ctrl+Alt+J** Next Source Passage

## Production

- **Ctrl+Shift+B** Tag Selection

## View

- **Ctrl+Shift+P** Preview PDF
- **Ctrl+Shift+O** Outline
- **Ctrl+Shift+D** Cards
- **Ctrl+Shift+.** Fold or Unfold Here
- **Ctrl+Shift+K** Notes
- **Ctrl+Shift+H** Changes
- **Ctrl+Shift+F, Alt+Enter** Fullscreen

## Not in a

- **Ctrl+F** Find and replace
- **F6** Next Pane
- **Shift+F6** Previous Pane
